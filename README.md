# AweTales_Speech_To_Speech_2300032488
Building an End-to-End Real-Time Speech-to-Speech Machine Translation System
This project is a Real-Time Speech Translation System that allows users to record or upload speech, convert it into text, translate the text into a selected target language, and generate translated speech audio.
The system integrates speech recognition, machine translation, and text-to-speech technologies into an interactive web application built with Streamlit.

Features:
-> Record speech using the microphone or Upload audio files (MP3/WAV)
-> Speech recognition using OpenAI Whisper
-> Multilingual translation using Meta NLLB-200
-> Multilingual translation using Meta NLLB-200
-> Interactive web interface built with Streamlit
-> Supports multiple languages such as: English,Telugu,Hindi,Tamil,French,Japanese, Korean
